## Empire 15 — Prototype (game-prototype)

Purpose
- Minimal playable loop: Spawn -> Move -> Capture Zone -> Zone changes color -> Timer updates -> Repeat
- Third-person player control (TPS), smooth movement & camera (polished feel).
- Minimal HUD showing role, cycle timer, and current zone status.
- Leader can draw a line; the nearest capture zone to the drawn line's endpoint becomes active (prototype behavior).

How to run (Unity 2023.4 LTS)
1. git checkout game-prototype
2. Open project in Unity 2023.4 LTS
